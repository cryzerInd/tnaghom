# تناغم المعمار | Tanaghom Al-Memar

الموقع التعريفي لشركة تناغم المعمار للاستشارات الهندسية في جدة، بصياغة سعودية وهوية ذهبية وفحمية.

https://cryzerind.github.io/tnaghom/

أربع صفحات: الرئيسية، الخدمات، كيف نشتغل، والتواصل. يتضمن الموقع 29 صورة من ملف أعمال الشركة، ومعرضًا يدعم التصنيف وتكبير الصور، وملف البروفايل بصيغة PDF.

المحتوى والصور من الملفات المقدمة من صاحب الموقع. التصورات موضحة كتصورات تصميمية. صورة البرج في غلاف البروفايل عمل توضيحي وليست ادعاء بمشروع منفذ.

موقع ثابت جاهز لـ GitHub Pages. النشر من الفرع main ومجلد الجذر.

جميع حقوق الصور والمحتوى محفوظة لأصحابها.
